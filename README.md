## Local Development

### Clone

```bash
git clone https://github.com/zamanimthembu/portfolio-website.git
cd portfolio-website
```

### Install

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
